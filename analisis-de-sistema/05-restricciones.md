## Restricciones

| **ID** | **Restricción** | **Descripción** |
|--------|-----------------|-----------------|
| **RC01** | **Aplicación web responsiva** | El módulo de consulta pública debe ser accesible desde un navegador web, incluyendo teléfonos móviles. |
| **RC02** | **Contenedores Docker** | El sistema debe desplegarse mediante contenedores Docker. |
| **RC03** | **Carga desde SQL Server** | El sistema debe actualizar sus datos mediante una carga desde una base de datos SQL Server. |
| **RC04** | **RENIEC** | El sistema debe integrarse con RENIEC para la validación de identidad (DNI). |
| **RC05** | **Alcance académico** | No se ejecutan pruebas de carga reales a escala de 10 000 usuarios ni se implementa alta disponibilidad multi-centro de datos; quedan como capacidad de diseño. |
